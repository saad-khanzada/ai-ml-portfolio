# AI/ML Portfolio

Professional, scalable AI/ML portfolio website built with Next.js, TypeScript, and Tailwind CSS.

## Purpose

This project is the foundation for a personal AI/ML portfolio focused on presenting projects, experience, skills, technical writing, and future AI-related work professionally.

The website is planned to support:

- AI/ML projects
- AI automation projects
- Agentic AI projects
- Technical case studies
- Blog and insight posts
- Experience and certifications
- Future CMS-driven updates through Sanity

## Current Stack

- Next.js
- TypeScript
- Tailwind CSS
- React
- GitHub

Planned later:

- Sanity CMS
- Vercel deployment
- Hostinger custom domain

## Local Development

Install dependencies:

    npm install

Run the development server:

    npm run dev

Open http://localhost:3000 in your browser.

Create a production build:

    npm run build

Run linting:

    npm run lint

## Architecture Direction

The project follows a modular structure using the Next.js App Router.

Content will later be managed through Sanity CMS, while presentation, layout, responsive behavior, animations, and advanced functionality remain controlled in code.
